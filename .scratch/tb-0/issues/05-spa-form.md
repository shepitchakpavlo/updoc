# 05 — SPA form

**What to build:** мінімальна мобільна SPA-форма працівника: відкриття лінка показує дані заявки і чекліст книжечки (слоти 1–2, 11–12, 13–14, 15–16), кожен слот приймає один файл (заміна — повторним завантаженням), стан слота і фідбек від API видно одразу. Тип документа в UI і панель оператора — Phase 1.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Лінк відкриває форму з даними заявки і чеклістом
- [ ] Кожен слот приймає один файл; повторне завантаження замінює
- [ ] Стан кожного слота видно (очікується / перевіряється / прийнято / потрібно перезавантажити)
- [ ] Фідбек від API показується (включно з причинами policy, коли вони з'являться)
- [ ] Ручний прохід: файл завантажується, стан оновлюється
