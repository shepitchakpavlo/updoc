# 07 — Policy gate

**What to build:** policy-рішення над результатом assessment: 3 критичні поля (ПІБ, номер документа, дата народження) з достатнім confidence + відповідність файла слоту; кожен reject має зрозумілу причину для фідбека працівнику. Невпевнений результат не приймається.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] Приймається лише читабельний файл відповідного слота з критичними полями
- [ ] Кожен reject має зрозумілу причину (фідбек)
- [ ] Невпевнений результат не приймається (рішення Architecture §6)
- [ ] Policy не знає про конкретного провайдера (працює над нормалізованим результатом)
